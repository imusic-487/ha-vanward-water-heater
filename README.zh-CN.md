# Home Assistant 万和热水器集成

[English](README.md) | 简体中文

这是一个用于万和热水器的 Home Assistant 自定义集成。

## 安装

通过 HACS 自定义仓库安装：

1. 打开 Home Assistant 中的 HACS。
2. 进入 `Integrations`。
3. 打开右上角菜单，选择 `Custom repositories`。
4. 添加仓库：

```text
https://github.com/orangeboyChen/ha-vanward-water-heater
```

5. 分类选择 `Integration`。
6. 安装 `Vanward Water Heater`。
7. 重启 Home Assistant。

## 使用

安装后进入：

```text
设置 -> 设备与服务 -> 添加集成
```

搜索 `Vanward Water Heater`，并按照配置流程完成添加。
