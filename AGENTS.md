# Agent Instructions

## Commit Style

Use Conventional Commits for every commit message.

Examples:

- `feat: add water heater platform`
- `fix: refresh expired cloud sessions`
- `docs: update HACS installation guide`

## Branches

Use `main` as the primary branch.

## Validation

Before committing, run the available local checks:

```bash
python3 -m compileall custom_components/vanward_water_heater
python3 -m json.tool custom_components/vanward_water_heater/manifest.json >/dev/null
python3 -m json.tool custom_components/vanward_water_heater/strings.json >/dev/null
python3 -m json.tool custom_components/vanward_water_heater/translations/en.json >/dev/null
python3 -m json.tool custom_components/vanward_water_heater/translations/zh-Hans.json >/dev/null
```

Do not commit local editor files, virtual environments, caches, or generated bytecode.
